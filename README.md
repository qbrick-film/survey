# 紫熊祭2026 上映アンケート 読み取りツール

映画研究部の上映アンケート（用紙 `SQ26-上映 v2`）をスキャンしたPDFを読み込み、
選択式の設問をマークシートとして自動で判定し、自由記述欄を画像で切り出すツールです。

## 使い始める

**https://qbrick-film.github.io/survey/** をブラウザで開くだけで使えます。インストールは要りません。

- 処理はすべてブラウザの中で行います。スキャンしたデータは、どこにも送られません。
- 用紙のPDF：[紫熊祭2026_上映アンケート.pdf](dist/紫熊祭2026_上映アンケート.pdf)
- 正しいアドレスは `qbrick-film.github.io/survey` です。ほかのアドレスで同じ画面が出ても使わないでください。

## 使い方

1. 用紙は拡大・縮小せず「実際のサイズ（100%）」で印刷します。
2. 回収した用紙はまとめてオートフィーダーでスキャンします（300dpi・グレースケール・片面、背景除去や白紙ページ除去はオフ）。
3. PDFをツールに読み込み、読み取れなかった用紙と要確認の箇所だけ目で確認します。
4. CSVを保存し、自由記述の切り出し画像はAIに文字起こしさせて、回答者番号で結合します（プロンプトは画面にあります）。

## 開発

- `src/gen.py`：用紙PDFと `src/layout.json`（座標定義）を作る。□・記述欄・四隅マークの位置は印刷済みの用紙と合わせるため変更しない
- `src/core.js`：判定ロジック（Node でテストできる純粋関数）
- `src/app.html`：画面
- `python3 build.py`：`dist/index.html`（GitHub Pages 用）を作る

`src/` を変えたら `python3 build.py` を実行し、`dist/` も一緒にコミットします。
main に push すると GitHub Pages に公開されます（組み立て直した結果が `dist/` と違うと止まります）。

テストは実スキャンを使うため、画像はリポジトリに入れていません（`tests/img/` に置いて使う）。
詳しい経緯と判定の工夫は [HANDOFF.md](HANDOFF.md) にあります。
